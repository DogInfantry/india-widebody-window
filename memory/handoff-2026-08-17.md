## Decisions taken, with the reasoning

- **Utilisation reported as owned-fleet, not active-fleet.** User chose "both as a band"; the
  floor was sourced but the ceiling could not be, so the band collapsed to its conservative
  end and the basis is named on the chart.
- **Capacity leg fleet-weighted.** User chose it. Two variants are announced by type but not
  variant (Air India's 10 Dec-2024 A350s and its 20 787s); both assumed to be the **smaller**
  type so the error runs against the argument, and both named on the chart face.
- **Profit pool stage lengths are reference distances, not traffic-weighted means.** A weighted
  mean needs DGCA city names matched to airport coordinates, which resolves only about half the
  traffic once both ends must match. A labelled reference beats a quietly wrong mean.
- **Commits carry no `Co-Authored-By` trailer.** User asked explicitly. The four commits that
  already had it were rewritten with `filter-branch` while still unpushed; content verified
  byte-identical before and after.

## Things that will waste your time if you do not know them

Full list is in `CLAUDE.md` under Gotchas. The three that were learned the hard way *this*
session:

- **`pdftotext` and `pypdf` are already installed.** Two prior sessions concluded PDFs were
  unreadable and left the project blocked. They are not. `pdftoppm` is missing so the Read tool
  cannot rasterise pages, but `pdftotext -layout` works.
- **Extracted PDF tables misalign columns.** IndiGo's operational highlights puts values one row
  below their label. Anchor on a known value before trusting anything read out of one.
- **Tests do not catch wrong buckets.** The Gulf-hub bug survived 72 passing tests. When a
  lookup depends on matching a string against source data, assert the literals resolve.
