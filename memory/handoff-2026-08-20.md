lower bound of **7.84M**.

East" is wider than the Gulf six. And the **5.6%** route-level cross-check is unchanged, because
IATA publishes country and region aggregates, not routes. Inflating it would have been
engineering a metric upward.

## Decisions taken this session

- **FY2027 is DROPPED**, by the user, on 2026-08-20. It was deferred on 08-19. The risk
  register records that three rows fired and by how much; modelling the consequences is closed.
  **Do not re-propose it.**
- **Motion is in, narrowly, and `Reveal` does not use it.** The Motion version wrote
  `opacity:0` into the exported HTML on six wrappers, so with JavaScript off or on a printed
  page six sections were invisible. The reveal is now one `IntersectionObserver` and two CSS
  rules with the default inverted: content is visible unless JS proves otherwise. Motion stays
  only for `CountUp`.
- **No map library.** MapLibre needs a tile source and a key; ECharts is a third chart library.
  `CorridorMap.tsx` is inline SVG with a hand-rolled projection over a committed Natural Earth
  outline. Same treatment Vizro and Bklit got: read the idea, cite it, do not depend on it.
- **shadcn, Kokonut, Aceternity, Vite, Plotly: patterns only, no installs.** Reasons are in
  `docs/external_review_response.md` and gotcha 71.
- **The austere palette holds.** No green-for-favourable, no illustration, no gradients. One
  red element per exhibit.

## Three corrections I had to make to my own reported work

Recorded because the pattern is the lesson, not the individual errors.

1. **"tsc clean" was reported several times against a command that cannot fail.**
   `npx --prefix web tsc --noEmit` prints tsc's help and exits 0. Gotcha 72. Use
   `cd web && npx tsc --noEmit`.
2. **"Cut a third of the prose" did not happen.** Word counts went UP on both pages rebuilt.
   The metric that actually moved was words-before-the-first-picture. Gotcha 77 records that
   "first visual as a percentage of page height" is a bad metric because it falls when a page
   gets longer; measure in screens.
3. **"Motion is broken in this stack" was wrong.** It was gotcha 33: the Browser pane does not
   composite when hidden, so `IntersectionObserver` never fires in it. A native observer
   attached by hand never fired either.

## The commands that matter

```bash
python -m pytest -q                      # offline, ~25s, 205 tests
python scripts/refresh.py --no-fetch     # rebuild figures from cached parquet
python -m src.app_export                 # rewrite web/public/data/ only
cd web && npx tsc --noEmit               # types. NOT `npx --prefix web`, see gotcha 72
npm --prefix web run build               # static export, what Vercel runs
```

**After changing any module that feeds a chart or the app, run BOTH `scripts/refresh.py
--no-fetch` and `python -m src.app_export`**, or the committed exports go stale and tests pass
against old data. Gotchas 10, 11, and the drift guard in `tests/test_app_export.py`.

**CI pushes its own monthly refresh commit**, so a push may be rejected as non-fast-forward:
`git fetch && git rebase origin/main`. It happened twice this session. **Verify actual values
after a rebase, not just that tests pass** (gotcha 16): one of those refreshes genuinely
re-pulled OurAirports and changed `airports.parquet`, which is where the corridor map's
coordinates come from. They had not moved, but that was checked rather than assumed.
