## Decisions taken this session

- **FY2027 is DROPPED**, by the user, on 2026-08-20. Deferred on 08-19, closed on 08-20. The
  risk register records that three rows fired and by how much; modelling the consequences is
  not being done. **Do not re-propose it.**
- **Motion is in, narrowly, and `Reveal` does not use it.** The Motion version wrote
  `opacity:0` into the exported HTML on six wrappers, so with JavaScript off or on a printed
  page six sections were invisible. The reveal is one `IntersectionObserver` and two CSS rules
  with the default inverted: content is visible unless JS proves otherwise. Motion stays only
  for `CountUp`.
- **No map library.** `CorridorMap.tsx` is inline SVG with a hand-rolled projection over a
  committed Natural Earth outline. MapLibre wants a tile source and a key; ECharts is a third
  chart library. Same treatment Vizro and Bklit got.
- **shadcn, Kokonut, Aceternity, Vite, Plotly: patterns only, no installs.** Gotcha 71 and
  `docs/external_review_response.md`.
- **The austere palette holds.** One red on greys, IBM Plex Serif and Sans, no green for
  favourable, no gradients, no illustration. **The blandness was never the palette**: it was
  the absence of a type scale, and the fix needed no colour at all.

## Four corrections I had to make to my own reported work

Recorded because the pattern is the lesson, not the individual slips. Every one was caught by
measuring rather than by inspection.

1. **"tsc clean" was reported several times against a command that cannot fail.**
   `npx --prefix web tsc --noEmit` prints tsc's help and exits 0. Gotcha 72. Use
   `cd web && npx tsc --noEmit`.
2. **"Cut a third of the prose" did not happen.** Word counts went UP on both rebuilt pages.
   Gotcha 77 records why "first visual as a percentage of page height" is a bad metric: it
   falls when a page gets longer. Measure in screens, at a viewport a reader uses.
3. **"Motion is broken in this stack" was wrong.** It was gotcha 33: the Browser pane does not
   composite when hidden, so `IntersectionObserver` never fires in it. A native observer
   attached by hand never fired either.
4. **"Swept the other tabs" was not true.** It was global CSS inheriting, not a design pass.
   The user caught it, correctly, and the type scale in `cfa4cab` is what actually fixed it.

## The commands that matter

```bash
python -m pytest -q                      # offline, ~30s, 205 tests
python scripts/refresh.py --no-fetch     # rebuild figures from cached parquet
python -m src.app_export                 # rewrite web/public/data/ only
cd web && npx tsc --noEmit               # types. NOT `npx --prefix web`, see gotcha 72
npm --prefix web run build               # static export, what Vercel runs
```

**After changing any module that feeds a chart or the app, run BOTH `scripts/refresh.py
--no-fetch` and `python -m src.app_export`**, or the committed exports go stale and tests pass
against old data. Gotchas 10, 11, and the drift guard in `tests/test_app_export.py`.

**CI pushes its own monthly refresh commit**, so a push may be rejected as non-fast-forward:
`git fetch && git rebase origin/main`. It happened twice today. **Verify actual values after a
rebase, not just that tests pass** (gotcha 16): one of those refreshes genuinely re-pulled
OurAirports and changed `airports.parquet`, which is where the corridor map's coordinates come
from. No hub had moved, but that was checked rather than assumed.

## Design invariants worth not relearning

- **Nine `--text-*` steps in `@theme`, zero ad-hoc font sizes.** If a new size is needed, add a
  step; do not write `text-[13.5px]`. Gotcha 82.
- **`.display` is once per page**, on the number or sentence that page exists for.
- **Links are underlined by default and opt out explicitly** via `.block-link` or
  `no-underline`. The direction is the point. Gotcha 74.
- **Motion never touches chart marks.** Every Recharts series sets `isAnimationActive={false}`
  and a test enforces it. Gotchas 70 and 78.
- **A full-bleed band needs `left-1/2 w-screen -translate-x-1/2`** and is the one reliable
  cause of horizontal scroll. Check 375px and 1440px every time. Gotcha 85.
